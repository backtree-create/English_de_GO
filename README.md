# 英語でGO!

日本語の意味を見て、英単語のつづりを制限時間内に打ちこむ小中学校向けのゲームです。
ビルド不要。ファイルをリポジトリの直下に置いて GitHub Pages を有効にするだけで動きます。

## 公開のしかた

1. GitHub で新しいリポジトリを作る（例: `eigo-de-go`）。**Public** にしてください。
2. このフォルダのファイルを**すべてリポジトリの直下**にアップロードする。
   （`Add file` → `Upload files` にまとめてドラッグ＆ドロップ）
3. リポジトリの `Settings` → 左メニューの `Pages` を開く。
4. `Build and deployment` の `Source` を **Deploy from a branch**、
   `Branch` を **main / (root)** にして `Save`。
5. 1〜2分待つと `https://ユーザー名.github.io/eigo-de-go/` で公開されます。

## ファイル一覧

| ファイル | 役割 |
|---|---|
| `index.html` | 入口。React と Babel を CDN から読みこみます |
| `app.jsx` | ゲーム本体。単語データもここに入っています |
| `manifest.json` | ホーム画面に追加したときの名前・アイコン設定 |
| `sw.js` | 2回目以降の起動を速くし、通信が切れても遊べるようにします |
| `icon.svg` / `icon-512.png` / `icon-192.png` | アプリアイコン |
| `apple-touch-icon.png` | iPhone・iPad でホーム画面に追加したときのアイコン |
| `favicon.ico` / `favicon-32.png` | ブラウザのタブに出る小さいアイコン |
| `.nojekyll` | GitHub Pages の余計な変換を止めます |

## 遊び方

- 全4ステージ。ステージ1〜3は各3問、ステージ4は難問1問の計10問です。
- 時間内なら打ちまちがえても何度でもやり直せます。**時間切れ3回で終了**。
- 時間切れになった問題は答えを表示したあと、同じステージの別の問題に差し替わります。
- 『q』と入力するとギブアップできます（時間切れ扱い）。
- 終了画面に、答えられなかった単語の復習リストが出ます。

## 授業で使うときのメモ

- 入力は**半角英数**です。始める前に生徒に `半角/全角` キーを押させてください。
  日本語が入力された場合は自動で弾いて赤い帯で知らせます。
- タイトル画面の `全画面表示` を押すと画面いっぱいに広がります（プロジェクター向け）。
- `BGM` `効果音` はいつでも切れます。`マスひょうじ` を OFF にすると文字数のヒントが消えて難しくなります。
- タブレットやスマホでも遊べます。入力欄をタップするとキーボードが出て、`決定` ボタンで解答できます。
- iPad などは、ブラウザの共有メニューから**ホーム画面に追加**するとアプリのように起動し、
  ブラウザのバーが消えて画面いっぱいに表示されます。Android は Chrome のメニューから
  **アプリをインストール**を選びます。

## 中身を書きかえるには

`app.jsx` の先頭にある `LEVELS` に単語が入っています。

```js
words: [
  ["library", "図書館"], ["question", "質問"],
]
```

この形式で行を足せば、お使いの教科書の単語リストをそのまま追加できます。
ステージ間で単語を移したいときは、行を別のステージの `words:` に移すだけです。

- 制限時間: `timeFor` の `(level.base + word.length * 0.5) * 2` を調整（`* 2` を下げると短くなります）
- 出題数: 各ステージの `count`
- 残機: ファイル上部の `MAX_LIFE`

## 収録語数

| ステージ | 割り振り | 語数 |
|---|---|---|
| 1 | 小学校＋中1 | 721 |
| 2 | 中2 | 639 |
| 3 | 中3 | 799 |
| 4 | 特に難しい語を厳選 | 179 |
| | **合計** | **2338** |

学年の割り振りは一般的な検定教科書の傾向に沿った目安です。お使いの教科書とずれる語は、
上記の方法で移動させてください。

## 注意

- パソコンのフォルダから `index.html` をダブルクリックしても動きません。
  ブラウザの制限のため、GitHub Pages の URL から開くか、
  ローカルで試すなら次のコマンドでサーバーを立ててください。

```
python3 -m http.server 8000
```

その後 `http://localhost:8000/` を開きます。

- ファイルを更新したのに画面が変わらないときは、`sw.js` の `CACHE = "eigo-de-go-v3"` の
  数字を `v4`, `v5` … と上げてからアップロードしてください。

- **すでにホーム画面に追加した端末は、古い画面を覚えたままになります。**
  更新後に表示が変わらないときは、ホーム画面のアイコンをいったん削除し、
  Safari / Chrome で開き直してから追加し直してください。
